# Combined-launcher execution rehearsal

This rehearsal exercises the [combined launcher](UNIFIED-LAUNCH.md) through the
original study and plain-reference controllers. It uses fresh synthetic tasks,
dummy keys, supplied worker messages and mocked HTTPS replies. It spends no
money, runs no operating-system containers and touches no actual study owners.

One reduced study setup is shared by the execution, interruption, resume and
completed-readback checks. Both declared child opportunities fail through the
worker protocol, leaving two starter assessment cells and two explicit missing
descendant slots. This keeps the integration check bounded; it does not measure
the effectiveness of the real improvers.

The passing execution covers:

1. The original primary study completes before either plain reference starts.
2. Independent generation completes and is sealed. An injected interruption
   stops before its first judging owner is created. The launcher saves the
   incomplete stage, cancellation and observed accounting.
3. The same descriptor resumes the same original roots and shared grant,
   finishes independent and in-context references, and publishes the comparison.
4. Completed replay checks saved evidence with keys, dispatch, controller
   execution and replacement-owner preparation forbidden.

Completed launch replay still creates and releases the normal operator lock;
the separate `--check` option supplies the read-only inspection route.

The test checks retained primary and generation bytes, owner identity, original
grant terms, actual mocked request counts, and combined accounting with the raw
grant counted once. The completed computation must still say that native and
human scientific reviews are pending separately.

The production funding/state checks, controllers, owner preparation and
comparison reader run unchanged. Worker execution and physical HTTPS are
substituted, so this cannot establish live-provider behavior, sandbox isolation,
full-grid timing, scientific independence or performance. Earlier actual
container checks retain their separate scope.

The fixture uses synthetic model profiles and supplied evaluator artifacts.
It does not certify the official judges' live decisions or replace the required
outgoing-request checks for the actual models before live use.

The single grouped test passed in 1,107.930 seconds (18 minutes 28 seconds),
without a failed run or restart. It observed 28 supplied workers and 25 mocked
HTTPS operations: 13 for the primary study and 12 for both references together.
The shared raw grant had eight original owners. All recorded synthetic costs
were settled, with zero held; none were actual provider charges. Existing
primary records, sealed independent generation, original owner identity and the
cancellation observation stayed unchanged during resume and completed replay.

[PLAN.md](PLAN.md) remains authoritative for the fresh configuration, hosted
verification, adoption and funded-handoff gates. This rehearsal grants no
spending permission and does not change the actual study's 3/26-task workload.
