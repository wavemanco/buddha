# Retired source proposal checker

The standalone source-experiment proposal checker has been retired with its
[launcher](SOURCE-LAUNCH.md). It used to check that selected files, configuration
and reviewed documents agreed before funding or key entry. It did not create a
budget, spend money or authorize execution.

The [original guide](https://github.com/wavemanco/buddha/blob/0e96fdbb3283f3747375597dc0fc1ce78a136a59/docs/SOURCE-HANDOFF.md) and
[checker source](https://github.com/wavemanco/buddha/blob/0e96fdbb3283f3747375597dc0fc1ce78a136a59/buddha/source_handoff.py) retain the versioned historical
interfaces. Versioned source-copy and mutation-witness behavior remains part of
the current [source-search controller](SOURCE-SEARCH.md); this retirement does
not change those policies or rewrite earlier records.

Frozen source copies, controls, grants and replies remain unchanged. The
[recorded first](SOURCE-FIRST-LIVE-RESULTS.md) and [current-source](SOURCE-CURRENT-LIVE-RESULTS.md)
experiments retain their original meaning. [PLAN.md](PLAN.md) owns the current
comparison. This page supplies no replacement command or new spending scope.
